# Climate Challenge Week 0

## Project setup

This repository is for the Week 0 setup task of the climate challenge.

## Requirements

- Python 3.10
- `venv` (built-in with Python)
- `pip`

## Reproduce the environment

### macOS / Linux

```bash
git clone https://github.com/selam-codes/climate-challenge-week0.git
cd climate-challenge-week0

python3 -m venv .venv
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

### Windows

```bash

git clone https://github.com/selam-codes/climate-challenge-week0.git
cd climate-challenge-week0

python -m venv .venv
.venv\Scripts\Activate

python -m pip install --upgrade pip
pip install -r requirements.txt
```
